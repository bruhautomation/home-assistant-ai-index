Notes

Two pieces: a HACS integration that feeds motion clips from your media folders (Unifi Protect focused) to a self-hosted GPU server running the Marlin-2B vision model, which captions events as background jobs and aggregates them into briefings via get_summary / get_instant_summary actions. Video never leaves your network; the optional cloud fallback sends only text. Young project (2026) — expect fast movement.
