Notes

From the Deepstack-era generation of vision integrations: YAML-configured, built on HA's legacy image_processing platform, and effectively in maintenance mode (recent activity is dependency bumps). It never scans on its own — frames go to AWS only when image_processing.scan is called, which keeps billing and data flow under your automations' control. AWS keys live in configuration.yaml.

Is this wrong about Amazon Rekognition? That's the bug we care about most — open a correction. Maintainer reports get priority.
