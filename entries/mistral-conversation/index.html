What it can reach

  • reads statesCan read the live state of entities exposed to it — temperatures, lights, locks, presence.
  • microphoneProcesses live audio — voice commands, wake words, or ambient sound.source ↗
  • controls devicesCan call Home Assistant services to switch, dim, unlock, or otherwise act on devices.

Not granted: reads history · reads camera · creates automations · edits files · executes code · unattended

Data flow

Providers/backends: mistral

What can leave your Home Assistant host:

  • conversation text, system prompt, and exposed entity states — to Mistral
  • voice audio, when selected as the pipeline's STT engine — uploaded to Mistral for Voxtral transcription
  • AI Task attachments such as camera snapshots — base64-uploaded to Mistral

Notes

A faithful mirror of the core OpenAI integration's shape — but broader by default: setup enables the Assist control API and auto-creates conversation, AI Task, and STT subentries, so once you pick it in a pipeline your voice clips go to Mistral too. Cloud-only, no custom base URL. Very new (first release July 2026, single maintainer) — the polish is real, the track record is short.
