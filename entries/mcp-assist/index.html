Notes

Solves the exposed-entity context-window problem with discovery tools instead of dumping every entity into the prompt. Tools stay bounded by Assist exposure, and there is no automation writing or file editing — though run_script can invoke your scripts, which may do more. Its internal MCP server also listens on TCP 8090 with an IP allowlist that defaults to localhost only.

Is this wrong about MCP Assist? That's the bug we care about most — open a correction. Maintainer reports get priority.
