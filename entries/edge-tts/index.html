Notes

Text goes out, audio comes back; it never hears anything. The convenience is the trade: it rides an unofficial free Microsoft endpoint that can rate-limit or break without notice, and it registers an unauthenticated /api/tts_proxy HTTP view guarded only by a long-lived query token — treat generated TTS URLs as sensitive.

Is this wrong about Microsoft Edge TTS? That's the bug we care about most — open a correction. Maintainer reports get priority.
