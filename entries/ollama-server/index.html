Notes

A model runtime, not a Home Assistant integration: it has no reach into your instance. It only sees what the integrations you point at it send — the core Ollama integration, Home LLM, LLM Vision, and anything OpenAI-compatible via its compatibility endpoint. Pairing cloud-capable integrations with a runtime like this is how camera frames and conversations stay home.
