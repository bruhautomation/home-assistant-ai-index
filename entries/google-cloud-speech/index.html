Notes

The cloud counterpart to the Whisper add-on: voice commands are streamed to Google's Speech API rather than transcribed on your hardware. Requires a Google Cloud service-account JSON key, so usage is billed and logged under your own GCP project — a clearer audit trail than consumer-keyed clouds, but off-network all the same.

Is this wrong about Google Cloud (STT/TTS)? That's the bug we care about most — open a correction. Maintainer reports get priority.
