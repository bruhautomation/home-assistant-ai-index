Notes

The model drives a tool loop that can call any HA service, write automations.yaml (with backup, atomically), and write dashboard YAML — including appending a lovelace section to configuration.yaml. The panel shows approve buttons for suggestions, but the backend also executes service-call and automation-create requests the model emits directly. Runs only when you chat with it or call its services.
