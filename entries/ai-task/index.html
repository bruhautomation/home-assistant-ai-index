Notes

This is the mechanism by which Home Assistant runs AI from triggers and schedules: an automation fires, AI Task resolves attachments (camera snapshots via media source) and sends them to the chosen provider. The framework returns data; acting on it is up to your automation. Which provider sees the data is decided per call, not per install.
