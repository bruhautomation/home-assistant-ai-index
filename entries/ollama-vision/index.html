Notes

Images arrive as URL or path strings — camera_proxy links, Frigate snapshot URLs, files under /config — rather than camera entities, and go to a server speaking the raw Ollama protocol with no API key, so this is built for self-hosted backends. Runs only when your automations call its service. An optional second text model rewrites the description.
