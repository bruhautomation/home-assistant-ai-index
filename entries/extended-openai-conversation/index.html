Notes

The function system is the power and the reach: native functions include execute_services, add_automation, and get_history, and the function library now also ships bash execution, file read/write/edit, Jinja template evaluation, SQL against the recorder database, web scraping, and REST calls. Which of these the model can use is decided by the functions you enable in its configuration. Local inference works via any OpenAI-compatible server.

Is this wrong about Extended OpenAI Conversation? That's the bug we care about most — open a correction. Maintainer reports get priority.
