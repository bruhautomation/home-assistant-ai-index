Notes

A pure router with no reach of its own: states, control, and data flow all belong to the agents it delegates to. Worth knowing anyway — a failed "local-first" query is re-sent verbatim to the fallback, so cloud can still see text you expected to stay local. The repo is archived (read-only) and targets the pre-2025 conversation API, so expect breakage on current HA.
