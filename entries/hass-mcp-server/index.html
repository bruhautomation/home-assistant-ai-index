Notes

The widest MCP tool surface of the three servers in the index — automation, scene, script, and helper CRUD, dashboards, HA restart, raw YAML editing. The riskiest tools (camera images, config-file editing) default off, secrets.yaml is blocked, and backups are taken before writes. Auth is bearer token: OIDC via the author's companion integration, or long-lived HA tokens if you enable native auth. What connects to it decides where your data goes.

Is this wrong about MCP Server (HTTP Transport)? That's the bug we care about most — open a correction. Maintainer reports get priority.
