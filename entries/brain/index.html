Notes

The widest capability surface in the index, by design: Supervisor admin role, read-write /config, and Bash pre-approved for headless runs, so automations can invoke the agent unattended. The counterweights are also in source: permission prompts stay on by default, every file edit is snapshotted to an undo journal first, the terminal port is unpublished by default, and backups exclude the Claude credential. Disclosure — this index is maintained by brAIn's author.

Is this wrong about brAIn? That's the bug we care about most — open a correction. Maintainer reports get priority.
